In Configure, Layout has Text and Modules controls beside Spacing, each Auto (follows Spacing), Tight, Balanced or Open. Text sets the gaps between the items of a block of text; Modules sets a module's padding above and below and the space between its own parts. Fill has a Quiet option, and the exported CSS carries all of them. The Layout foundation page gains a Text and modules card.
