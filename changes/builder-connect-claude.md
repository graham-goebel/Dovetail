Builder: Connect Claude lets someone use the Claude they already have, on its own plan and with no API key, to edit their open canvas. It's in a file's ⋯ menu, the Agent panel's menu and the agents dialog. It makes one link to add to Claude as a custom connector. Claude then works on the Builder tab in view with the Agent panel's own tools, shown in the top bar and the Session panel like any agent, with every step undoable. A new link replaces the old one, and Disconnect ends it.
