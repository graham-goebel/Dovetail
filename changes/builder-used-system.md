With nothing selected on the Builder page (`builder.html`), the inspector's Variables, Primitives and Styles list what the project uses, across all its pages.

- Colour lists the surfaces in use. Spacing, Radius and Shadow list the token options its styles name. Primitives lists the ones placed, however deep. Text lists the text styles its components are set in, defaults included.
- A group with nothing in use says so.
- A switch at the top, In this project or Everything, shows the whole system again.
