The Builder's assistant can see more than the selection. It lists the file's pages, reads any page as an outline of its layers, looks up a component's props and documentation, and takes a picture of a frame or layer to check what it made; the picture shows in the thread beside the step. Every conversation starts from a brief built from the design system (its rules, components and token values) that stays the same between requests, so it's cached. The model's progress notes between tool calls show as steps. Practice mode answers "what's on this page", "take a look" and "which component for…" with the real tools, so nothing is sent.
