A conversation with the assistant can be shared in a file: signed in, with the file in the cloud, **Share in this file** in the assistant panel's ⋯ menu lets everyone on the file read it and carry it on, each message naming who sent it. Conversations others shared are listed under "Shared with you". Only the starter can share, unshare or delete one.
