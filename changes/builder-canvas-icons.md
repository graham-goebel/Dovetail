The Builder draws its controls with a new set of canvas icons: alignment, layout, layers, tools, booleans, playback and everyday actions. Each icon moves once while its control is hovered or focused, stays still at rest, and never moves when reduced motion is on. The icons are MIT licensed and live in `assets/builder/icons/canvas`. Which Builder icon uses which canvas icon is set in `assets/builder/icons/use.json`. Icons not listed there keep their old drawings.
