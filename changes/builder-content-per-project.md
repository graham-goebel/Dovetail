On the Builder page (`builder.html`), uploaded content belongs to the project.
- **Per project:** images, illustrations, video, icons and your own components are shared by the files in a project and never shown in another project. A loose file has its own.
- **Moving files:** when a file moves into or out of a project, its content comes along. Copying a project copies its content, and deleting a project deletes its content.
- **Earlier files:** files made before this change go on sharing the one library they used, so nothing is lost.
- **Content panel:** it says whose content you're looking at.
- **Logo and brand mark:** these stay with the file's theme and its frames. The builder's own header keeps the Dovetail name. On a page marked `data-theme-fixed` (the builder), `assets/theme.js` no longer repaints the page's wordmark.
