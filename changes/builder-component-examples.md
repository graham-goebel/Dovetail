A component's page in the Builder's Assets panel now shows examples built from it under the live preview, the way its docs page does: Card as a plan, an interactive or selected plan, with media, a settings panel and a stats panel, with what goes in their slots (a footer Button, an Image in the media slot); every block in its layouts, tones and dark; and, for any other component, one example for each option of its main choice (variant, layout, tone…). Pressing an example starts the preview and properties from it, so it can be changed before Insert; dragging one places it on a frame as it is. Card's tile now opens its page too, instead of adding a blank Card at once.
