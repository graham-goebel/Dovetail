"Open in Claude" hands Claude a prompt that points it first at a new `llms.txt` docs map, then at the page you're on, then at the authoring rules. The prompt lists the rules generated code most often breaks and ends on "My task:" so you only type what you want.

`llms.txt` is generated at the site root and links the raw Markdown or JSON for every guide, token file and component (guide, props and source).
