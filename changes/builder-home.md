On the Builder page (`builder.html`), Home replaces the Projects button.

- Home is first in the left rail. It opens a page of every project over the canvas: open one, start a new one (blank or from a template), rename, give it a picture, duplicate, download, delete, or open a `.dovetail` file. The bar names the page and has Back to the project you were in; Escape goes back too.
- The canvas stays where it was underneath, so going back is instant.
- The projects button has left the bar. All projects is still in the project's menu (…).
