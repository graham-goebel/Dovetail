Signed in, the Builder keeps every file in the cloud as well as in this browser: files in this browser go up on sign-in, files from another browser come down, and each save follows a moment later. A file opens at once and offline; when a page was saved elsewhere first, the cloud's copy wins and what was here is kept under Versions as "Before reloading from the cloud". The Account dialog says how the last sync went.
