The Builder's Auto layout section now has a button in its head that turns auto layout on or off for the selected Group, and for a freeform frame when nothing is selected. When auto layout is off, the section shows only the **Add** button. Turning it on lays out what the Group or page holds in a row or a column, in the order it stands, with the nearest gap and padding tokens, and the section opens to its controls. The minus button turns it off again and pins each layer where the layout put it. Shift+A does the same, and the right-click menu now reads **Add auto layout** and **Remove auto layout**. All of this now works on any Group in a freeform frame, not only a loose one whose children were all placed freely. While a freeform frame has auto layout on, something dropped on its page lands in the flow. Structured frames keep auto layout always on.
