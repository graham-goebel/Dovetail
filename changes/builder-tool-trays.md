The Builder page's (`builder.html`) tool bar is larger and squarer, with tools grouped into trays.

- **Larger bar:** buttons are a large control's size in a softly rounded bar, and a smaller control's size on a phone.
- **Trays:** Select and Hand stand alone. Each group opens a tray above the bar, and shows the last tool picked from it:
  - **Layout:** Group, Section, Frame and Page;
  - **Shapes:** Rectangle and Ellipse;
  - **Text:** Text and Heading;
  - **Images and media:** Image, Video, Cover, Media and Figure, with Icons and Illustrations marked coming soon.
- **Page:** adds a frame that hugs its content, started with a Section.
- **Typing:** Text and Heading open for typing as soon as they're placed.
- **Keys:** V, H, B, F, R, O, T and I still pick their tools. Escape closes an open tray.
