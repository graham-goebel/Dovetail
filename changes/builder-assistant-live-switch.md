The Builder's assistant panel has a **Live assistant** switch in its ⋯ menu: with the cloud connected and a person signed in, it sends requests to the model through the cloud instead of answering from the practice script, and the panel's badge reads Live or Practice to say which. Signed out, the menu offers to sign in. Before, live mode could only be turned on from browser storage.
