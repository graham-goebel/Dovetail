The Builder's assistant reuses what the file already has. `insert_template` adds one of the Builder's templates into the frame or as a frame of its own. `list_components` lists the file's own components, `insert_instance` puts one down as a linked instance, and `make_component` turns a layer into a component that becomes its first instance.
