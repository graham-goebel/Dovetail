A project on the Builder page (`builder.html`) can have several pages, each its own canvas of frames.

- The left panel has a Pages tab. Add a page with its plus button, and click a page to open it. Each page's menu offers Rename (or double-click the name), Duplicate, Move up, Move down and Delete, which asks first. A project keeps at least one page.
- Going to another page saves the one you're leaving. Each page keeps its own undo while the project is open, and versions are kept per page.
- A project opens on the page you last had open. Its card on the Projects home counts its pages.
- Downloaded project files carry every page, and opening one brings them all back. Files from before pages open as a single page.
- The Variables card in Assets shows an icon, like the cards beside it.
