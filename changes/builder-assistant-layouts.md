The Builder's assistant builds sections from a library of 18 tested layouts (heroes, features, stories, proof, moving showcases, steps, questions and closes) through two new tools, `search_layouts` and `insert_layout`, and gives each variant different layouts rather than only different colours. The checks now count each block as a section of its own, so a page of blocks with one primary button in each no longer warns.
