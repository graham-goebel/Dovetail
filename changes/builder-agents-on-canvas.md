Several agents can now edit an open canvas at once. **Let agents edit…** (in a file's ⋯ menu) lists the agents working on the file and adds another, each with its own link, name and colour; an agent's `hello` step sets its name and a small square mark of its own. Each agent's cursor and avatar sit on the layer it last changed, the top bar shows everyone working with Pause all and End all, and the Session panel filters steps by agent with an undo for one agent's changes. A layer one agent is changing is held for a moment, and another agent's step that needs it waits or says which agent is busy.
