The Builder's assistant keeps several conversations per file. The list button in its header shows them newest first, each with what was said last and the changes still standing; any can be opened or deleted, + starts a new one, and the one left open reopens with the file. A file's single earlier conversation becomes its first. Each message records who sent it. The cloud schema gains `assistant_threads` for conversations shared in a file, which anyone on the file can read and carry on; sharing from the panel waits for files to be kept in the cloud.
