The Builder's assistant knows when to use each part of the system. Its brief gives every component's purpose with when to use it and when not to, and token values carry their meaning, all read from the system's docs at build time. It can read a guideline in full and the file's theme. The checks gain a usage row that flags a component used against its docs, such as a danger button for an action that destroys nothing, a card inside a card, a Section inside a Section, or more than one Callout in a section.
