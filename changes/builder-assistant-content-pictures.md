The Builder's assistant uses the file's own pictures: a new `find_images` tool lists the Content uploads, and the assistant puts one in wherever a picture goes (a layout, an Image or Cover, a prop) as `content:<id>`, which the Builder swaps for the upload. A picture an agent sends to an open canvas is kept in Content too, named for what it shows. The assistant function now takes up to 40 tools.
