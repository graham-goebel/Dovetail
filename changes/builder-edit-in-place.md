On the Builder page (`builder.html`), double-click any text on the canvas to type into it where it is, including text inside a component.

- Typing in place now works on any of a component's text props, set or still the sample's, not only its main text.
- It also works on the text of one item in a list the component shows: a feature's title in a feature grid, a question in an FAQ, a link in a nav, a stat's label. The change goes into that item's field in the component's own list. A list still on its sample becomes the component's own first, with the other items kept.
- Enter keeps the change as one step, Escape takes it back, and undo puts back what was there, the sample included.
