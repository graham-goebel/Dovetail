The Builder's own tools (`builder.html`) are dark by default. A **Dark mode** switch on Home, and a Light mode / Dark mode item in the File menu (⋯) in the top bar, turn it off or on, and the browser remembers the choice (`dovetail-builder-dark`). Frames keep their own light or dark setting each, and the Configure panel's colour mode reaches the frames, not the tools, as before.
