A file in the cloud can be shared: the people in the Builder's top bar open a Share panel that lists who's on the file, invites by email, withdraws an invite, takes someone off (the owner) or leaves (anyone else). An invited person finds the file on their Home once they sign in with that address. Deleting a file shared with you leaves it instead of deleting it for everyone.
