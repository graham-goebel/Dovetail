In the Builder, a selected frame now opens with **Position** and **Size** sections, as a layer does. Position sets where the frame sits on the canvas (X and Y, below zero too). Size holds the device, width, height, constrain proportions, swap and resizing, which used to sit under the frame's name. With nothing selected, the inspector shows only the canvas's background. The Primitives and Styles lists are gone from there, since Assets on the left already has them.
