Install and import

Icon is in @dovetail-ds/react. Install it with React, if you haven't:

npm install @dovetail-ds/react react react-dom
import { Icon } from "@dovetail-ds/react";

Import @dovetail-ds/react/styles.css once at your app's root, then your theme after it. Setup covers the stylesheets, fonts and dark mode.

Guidelines

One glyph from Dovetail Icons, the system's own library of 320 icons, to mark an action, a status or a kind of thing.

Use it next to text, or on its own when its meaning is clear.

Use it when

  • A label, list row or heading reads faster with a mark beside it.
  • A control needs a glyph: pass <Icon /> to a component's icon slot, such as Button's.
  • A feature row or empty state wants a picture smaller than an illustration.

Don't use it when

  • The picture carries the message. Use Image or an illustration.
  • It would be the only way to tell two things apart. Pair it with text.
  • You need a brand mark. Upload it and place it as an Image.

Example

<Icon name="search" />
<Icon name="bell" size="sm" />
<Icon name="success" label="Saved" />

Sizes

sizepxdrawing
xs1216 grid, 1px strokes
sm1616 grid, 1px strokes
md2024 grid, 1.5px strokes
lg2424 grid, 1.5px strokes (the default)
xl3224 grid, 1.5px strokes

The size picks the drawing, so a 16px icon is its own drawing, not a shrunken 24px one. Sizes follow --dt-size-icon-*, so a context that re-points those tokens resizes icons too.

The library

Icon.names lists every name and Icon.groups lists them by category. The SVGs, 16 and 24, and a sprite sheet for each size are in system/assets/icons/dovetail/. Sprite ids are dt-NAME-16 and dt-NAME-24.

Composition

Inline: it sits on the text baseline and doesn't stretch in a row. Put it inside Button, Inline, list rows, Badge or Card. It takes no children.

Tokens

--dt-size-icon-xs to --dt-size-icon-xl for its box. Colour is currentColor, so it takes the text colour around it; set the colour on its container, never on the icon.

Accessibility

Without label the icon is decorative: aria-hidden, and skipped by screen readers. With label it is role="img" with that name. In an icon-only button, label the button and leave the icon unlabelled.

Content

Labels are short nouns or states in sentence case: "Saved", "Unread messages".

Props

The typed contract, from Icon.d.ts.

import * as React from "react";

/** One glyph from Dovetail Icons v1, the system's own library of 320 icons. */
export interface IconProps extends Omit<React.SVGAttributes<SVGSVGElement>, "name"> {
  /** The icon's name in the library, such as "home", "search" or "arrow-right". Icon.names lists them all. Unknown names draw "star". @default "star" */
  name?: string;
  /** Size from --dt-size-icon-*: xs 12, sm 16, md 20, lg 24, xl 32. xs and sm use the drawings made for the 16px grid. @default "lg" */
  size?: "xs" | "sm" | "md" | "lg" | "xl";
  /** Accessible name. Give one when the icon means something on its own; leave it out when text beside it says the same, and the icon is hidden from screen readers. */
  label?: string;
}

export declare function Icon(props: IconProps): React.JSX.Element;
export declare namespace Icon {
  /** Every icon name, in catalogue order. */
  const names: string[];
  /** The names by category, as [category, names] pairs. */
  const groups: Array<[string, string[]]>;
}

export function Icon({ name = "star", size = "lg", label, style, ...rest }) {
  const drawing = DRAWINGS[name] || DRAWINGS.star;
  const small = SMALL[size];
  const grid = small ? 16 : 24;
  const body = !drawing ? "" : small ? drawing[0] : drawing[1] || `<g transform="scale(1.5)">${drawing[0]}</g>`;
  const stroke = small || !drawing ? 1 : drawing[1] ? drawing[2] : 1;
  const box = SIZES[size] || SIZES.lg;
  return (
    <svg
      xmlns="http://www.w3.org/2000/svg"
      viewBox={`0 0 ${grid} ${grid}`}
      fill="none"
      stroke="currentColor"
      strokeWidth={stroke}
      strokeLinecap="round"
      strokeLinejoin="round"
      focusable="false"
      role={label ? "img" : undefined}
      aria-label={label || undefined}
      aria-hidden={label ? undefined : true}
      data-icon={name}
      style={{ width: box, height: box, flex: "none", display: "inline-block", verticalAlign: "middle", ...style }}
      dangerouslySetInnerHTML={{ __html: body }}
      {...rest}
    />
  );
}
