Files: [Quote.jsx](https://graham-goebel.github.io/Dovetail/system/components/content/Quote.jsx), [Quote.d.ts](https://graham-goebel.github.io/Dovetail/system/components/content/Quote.d.ts), [Quote.md](https://graham-goebel.github.io/Dovetail/system/components/content/Quote.md).

## Guidelines

Testimonial or pull quote. Uses `figure` and `blockquote` so the attribution is
programmatically tied to the words.

### Rules

- Do not add quotation marks in the content. If the design calls for them, they belong
  in the component, not the copy.
- Always attribute. An unattributed testimonial is marketing copy pretending to be
  evidence.
- `lg` is for a single hero quote per page. Using it for a row of three testimonials
  makes none of them stand out.
- Keep quotes under roughly 40 words. Longer ones stop being quotable.

### Tradeoffs

Large quote type competes with the page heading. On a landing page, pick one of the two
to be the largest thing on screen.

## Props

```ts
import * as React from "react";

/** Pull quote or testimonial with attribution. */
export interface QuoteProps extends React.HTMLAttributes<HTMLElement> {
  /** The quoted text, without quotation marks. */
  children?: React.ReactNode;
  /** Who said it. */
  attribution?: React.ReactNode;
  /** Their title or company. */
  role?: React.ReactNode;
  /** Avatar element for the speaker. */
  avatar?: React.ReactNode;
  /** @default "md" */
  size?: "md" | "lg";
}

export declare function Quote(props: QuoteProps): JSX.Element;
```

## Source

```jsx
import React from "react";

export function Quote({ children, attribution, role, avatar, size = "md", style, ...rest }) {
  const t = size === "lg" ? "heading-sm" : "body-lg";
  return (
    <figure style={{ margin: 0, display: "flex", flexDirection: "column", gap: "var(--dt-space-stack-sm)", ...style }} {...rest}>
      <blockquote style={{
        margin: 0, fontFamily: `var(--dt-text-${t}-family)`, fontSize: `var(--dt-text-${t}-size)`,
        lineHeight: `var(--dt-text-${t}-line)`, color: "var(--dt-text-primary)",
        fontWeight: size === "lg" ? "var(--dt-font-weight-medium)" : "var(--dt-font-weight-regular)",
        textWrap: "pretty", maxWidth: "54ch",
      }}>{children}</blockquote>
      {(attribution || avatar) && (
        <figcaption style={{ display: "flex", alignItems: "center", gap: "var(--dt-space-inline-sm)" }}>
          {avatar}
          <span style={{ display: "flex", flexDirection: "column" }}>
            {attribution && <span style={{ fontFamily: "var(--dt-text-label-md-family)", fontSize: "var(--dt-text-label-md-size)", fontWeight: "var(--dt-font-weight-medium)", color: "var(--dt-text-primary)" }}>{attribution}</span>}
            {role && <span style={{ fontFamily: "var(--dt-text-body-sm-family)", fontSize: "var(--dt-text-body-sm-size)", color: "var(--dt-text-secondary)" }}>{role}</span>}
          </span>
        </figcaption>
      )}
    </figure>
  );
}
```
