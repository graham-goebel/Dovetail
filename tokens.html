Tokens

Every token the system declares, with its value in each theme. Components read the semantic tier; only chart code reads a primitive, and it says why.

The tier rule is a claim about direction, and the graph is where you check it. Open the visualiser on any row to see what a token resolves through and, more to the point, which roles and components consume it.
